# algebra-calc-drill_JP
正負の数・数式の計算練習サイト（中学生向け） (Basic Algebra Practice Web App)

中学生から大人まで、数学の基礎体力である「計算力」と「計算の仕組みを読み解く力」を鍛えるための無料ウェブアプリケーションです。
論理的な理解を深めるためのスモールステップでの学習をサポートします。

## 🌐 サイトURL
[https://logigritlab.github.io/algebra-calc-drill_JP/](https://logigritlab.github.io/algebra-calc-drill_JP/)

## ✨ 主な特徴
- **幅広い学習範囲**: 「正負の数」「単項式」「多項式」の3分野を網羅しています。
- **柔軟なカスタマイズ**: 四則演算（和・差・積・商）の選択に加え、扱う文字の種類（1〜3個）を設定可能です。
- **丁寧なステップ解説**: 単なる正解の提示だけでなく、「なぜそうなるのか」を導く途中式を表示します。
- **直感的なUI**: スマホやタブレットでも見やすく、サクサク動作するレスポンシブデザインを採用しています。
- **美しい数式表示**: `KaTeX` ライブラリを使用し、本格的で読みやすい数式レンダリングを実現しました。

## 🛠 使用技術
- HTML5
- CSS3 (Vanilla)
- JavaScript (Vanilla / ES6)
- [KaTeX](https://katex.org/) (数式レンダリング用)
※ビルドツールや複雑な環境構築は不要です。






# English Version

# Basic Algebra Practice Web App

A free web application designed to help middle school students and adult learners build foundational math skills. It supports a logical, small-step learning approach to understand the mechanics behind calculations, rather than relying on rote memorization.

## 🌐 Live Demo
[https://logigritlab.github.io/algebra-calc-drill_JP/](https://logigritlab.github.io/algebra-calc-drill_JP/)

## ✨ Features
- **Comprehensive Topics**: Covers positive and negative numbers, monomials, and polynomials.
- **Flexible Customization**: Choose the type of operation (addition, subtraction, multiplication, division) and the number of variables (1 to 3).
- **Detailed Step-by-Step Explanations**: Shows intermediate steps to explain "why" the answer is what it is. For polynomial division, it visually reconstructs the long division (hissan) process.
- **Intuitive UI**: A responsive, fast-loading design optimized for both mobile and desktop screens.
- **Beautiful Math Rendering**: Powered by the `KaTeX` library for clean and professional mathematical typography.

## 🛠 Tech Stack
- HTML5
- CSS3 (Vanilla)
- JavaScript (Vanilla / ES6)
- [KaTeX](https://katex.org/) 
*No build tools or complex environment setups are required.*
