# 正負の数・数式の計算練習サイト（中学生向け）

中学生から大人まで、数学の基礎体力である「計算力」と「計算の仕組みを読み解く力」を鍛えるための無料ウェブアプリケーションです。論理的な理解を深めるためのスモールステップでの学習をサポートします。

## 🌐 サイトURL
https://logigritlab.github.io/algebra-calc-drill_JP/

## ✨ 主な特徴
- **幅広い学習範囲**: 「正負の数」「単項式」「多項式」の3分野を網羅しています。
- **柔軟なカスタマイズ**: 四則演算（和・差・積・商）の選択に加え、扱う文字の種類（1〜3個）を設定可能です。
- **自然な出題バランス**: 多項式の掛け算において、教科書や市販の問題集でよく見られる「$x$ の係数が正の数」になる問題の出題率を最適化。学習者が違和感なく実践的なトレーニングを積めるよう工夫しています。
- **丁寧なステップ解説**: 単なる正解の提示だけでなく、「なぜそうなるのか」を導く途中式を表示します。
- **直感的なUI**: スマホやタブレットでも見やすく、サクサク動作するレスポンシブデザインを採用しています。
- **美しい数式表示**: KaTeXライブラリを使用し、本格的で読みやすい数式レンダリングを実現しました。

## 🛠 使用技術
- HTML5
- CSS3 (Vanilla)
- JavaScript (Vanilla / ES6)
- KaTeX (数式レンダリング用) 

※ビルドツールや複雑な環境構築は不要。ブラウザのみですぐに動作・開発が可能です。
